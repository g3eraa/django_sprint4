# Блогикум

Блогикум — социальная сеть для ведения личных блогов: пользователи публикуют
посты с картинками, комментируют записи друг друга и ведут свою страницу.

## Возможности

- регистрация, вход и выход, смена и восстановление пароля;
- страница пользователя с информацией о нём и его публикациями; владелец
  страницы может отредактировать профиль и сменить пароль;
- создание, редактирование и удаление публикаций, картинки к постам;
- отложенные публикации: пост с датой в будущем появится на сайте в указанное
  время, а автор видит его сразу;
- комментарии: добавление, редактирование и удаление своих комментариев;
- пагинация — по 10 публикаций на главной, на странице категории и на
  странице пользователя;
- собственные страницы ошибок 403 (CSRF), 404 и 500;
- категории и местоположения создаёт администратор в админ-панели.

Письма (например, для восстановления пароля) не отправляются по почте,
а сохраняются файлами в директорию `blogicum/sent_emails/`.

## Технологии

Python 3.10, Django 3.2, django-bootstrap5, Pillow, SQLite.

## Как запустить проект

```bash
git clone git@github.com:g3eraa/django_sprint4.git
cd django_sprint4
python3.10 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd blogicum
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Чтобы наполнить сайт тестовыми публикациями, перед запуском можно загрузить
фикстуры:

```bash
python manage.py loaddata ../db.json
```

Сайт будет доступен по адресу http://127.0.0.1:8000/,
админ-панель — http://127.0.0.1:8000/admin/.

## Тесты

Из корня репозитория, с активированным виртуальным окружением:

